A tiny entry for the make.fun "One Line, One Laugh" bounty. `main.ts` writes a single
joke to `/output/entry.txt` (UTF-8, no trailing newline), after checking that it is
1-200 characters long and not just whitespace.

Run it with:

```
node main.ts
```
